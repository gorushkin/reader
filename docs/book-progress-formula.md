# Расчёт общего прогресса чтения

## Цель

Необходимо определить общий прогресс чтения книги, имея:

-   общий размер книги;
-   размер текущего чанка;
-   положение пользователя внутри текущего чанка.

Данная модель используется для отображения общего прогресса чтения и для приблизительного восстановления позиции внутри чанка.

------------------------------------------------------------------------

## Термины

### Размер книги (`book.totalExtent`)

Сумма размеров всех чанков книги.

    book.totalExtent = lastChunk.startExtent + lastChunk.extent

### Размер чанка (`chunk.extent`)

Условный размер чанка. Reader Core не зависит от способа его вычисления.

### Начало чанка (`chunk.startExtent`)

Сумма размеров всех предыдущих чанков.

  Chunk     Extent   StartExtent
  ------- -------- -------------
  A             10             0
  B             30            10
  C             20            40

### Прогресс внутри чанка (`chunkProgress`)

Относительное положение пользователя внутри текущего чанка. На текущем прототипе значение обозначает начало текущей видимой страницы и считается по колонкам:

    currentColumnIndex =
        min(
            currentPageIndex × visibleColumns,
            columnCount - 1
        )

    chunkProgress =
        currentColumnIndex / columnCount × 100

Где:

-   `currentPageIndex` --- индекс текущего навигационного шага внутри чанка, начиная с `0`;
-   `visibleColumns` --- количество колонок, видимых за один шаг навигации;
-   `columnCount` --- количество колонок, в которые разложился текущий чанк.

Диапазон:

    0.0 … 100.0

------------------------------------------------------------------------

# Формула

    bookProgress =
    (
        chunk.startExtent
        + chunk.extent × (chunkProgress / 100)
    )
    /
    book.totalExtent

где:

-   `bookProgress` --- общий прогресс книги (`0…1`);
-   `chunk.startExtent` --- размер книги до начала текущего чанка;
-   `chunk.extent` --- размер текущего чанка;
-   `chunkProgress` --- прогресс внутри чанка;
-   `book.totalExtent` --- общий размер книги.

------------------------------------------------------------------------

# Пример

    book.totalExtent = 100

    Chunk A:
    extent = 35
    startExtent = 0

    Chunk B:
    extent = 20
    startExtent = 35

    Chunk C:
    extent = 45
    startExtent = 55

    currentPageIndex = 1
    visibleColumns = 1
    columnCount = 5

    chunkProgress = (1 × 1) / 5 × 100 = 20

Получаем:

    bookProgress =
    (35 + 20 × (20 / 100)) / 100

    = 39%

------------------------------------------------------------------------

# Независимость от подготовки книги

Reader Core использует только подготовленные данные:

    Book
    ├── totalExtent
    └── Chunk[]
        ├── extent
        ├── startExtent
        └── content

Источник этих данных не имеет значения:

-   local-first --- веса вычислены локально;
-   серверная подготовка --- веса вычислены заранее на сервере.

Для Reader Core модель остаётся одинаковой.

------------------------------------------------------------------------

# Сохранение прогресса

Для синхронизации и локального восстановления позиции сохраняется не общий процент книги, а позиция внутри чанка:

    ReadingProgress
    ├── chunkIndex
    └── chunkProgress

Где:

-   `chunkIndex` --- индекс текущего чанка;
-   `chunkProgress` --- прогресс внутри чанка в диапазоне `0.0…100.0`.

При восстановлении Reader:

1. находит чанк по `chunkIndex`;
2. рендерит его контент;
3. после DOM-измерения получает `columnCount`;
4. переводит `chunkProgress` обратно в ближайший `currentPageIndex`.

Общий процент книги заново вычисляется по формуле выше и не хранится как источник истины.
